# 공식 A-SPICE 4.1 원문 발췌 (선택)

이 파일은 비어 있습니다. 정확한 GP 번호/원문 문구, 공통작업산출물(GWP) 목록, 프로세스별
베이스 프랙티스(BP)/작업산출물(WP) 목록이 필요할 때, 공식 A-SPICE 4.1 프로세스 평가 모델 문서(PDF 등)에서
관련 부분을 그대로 붙여넣어 두면 감사원 스킬이 이 파일을 우선 참조합니다.

원문 PDF를 저장소에 함께 두는 것도 가능합니다 (예: `docs/A-SPICE_4.1_원문.pdf`) —
이 경우 이 파일에는 PDF 경로만 적어두어도 됩니다.

## 예시 형식

```
## PA 2.1 GP 2.1.1
원문: "..."
출처: A-SPICE 4.1 프로세스 평가 모델, p.XX
```
