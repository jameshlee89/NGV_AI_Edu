# 회사 지정 요구사항 템플릿 (사용자 제공 예정)

이 파일은 아직 비어 있습니다. 요구사항 문서에 반드시 따라야 할 회사 지정 템플릿(항목 구성, 문서
양식, 필수 필드 등)을 여기에 붙여넣거나, 템플릿 파일이 저장소 어디에 있는지 경로를 적어두세요.

이 파일이 채워지면 `requirements-analyst` 스킬은 SKILL.md §1의 잠정 구조 대신 **이 템플릿을
우선 적용**합니다.

## 예시 형식

```
## 템플릿 위치
docs/templates/requirements_template.xlsx

## 또는 직접 붙여넣기
- 필드1: ...
- 필드2: ...
```
